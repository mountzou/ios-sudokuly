# Flow navigation icons

The user selected the Flow concept on 2026-10-24 for the home screen's statistics/history and account actions. `flow-selected-reference.png` preserves that exact selected visual target.

The custom silhouettes in `FlowStatistics.imageset` and `FlowAccount.imageset` were traced from the enlarged glyphs in that reference and normalized into 24 × 24 SVG view boxes. Their solid shapes and curved negative-space cuts come from the selected concept. They do not depend on an icon library.

Both asset catalogs preserve vector representation and use template rendering. The home header renders each asset in a 26 × 26 pt frame, tinted with `Palette.ink`, inside the existing 44 × 44 pt button. Button actions, accessibility labels and identifiers are preserved.
