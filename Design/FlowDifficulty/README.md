# Flow steps difficulty icons

The user selected `flow-steps-selected-reference.png` on 2026-10-25 to replace the home difficulty bars. These four custom SVG assets retain the selected flowing silhouettes, curved channels and four visible bars in every state.

`FlowDifficulty1` through `FlowDifficulty4` show one through four active charcoal bars, respectively, with the remaining bars in light grey. Each asset was traced from its corresponding state in the selected reference and normalized into a 30 × 30 view box. Original rendering preserves both colors; the asset catalog retains the vector representation.

The difficulty list uses the existing `Difficulty.rank` to choose the image. Its 30 × 30 pt icon slot, row actions, durations and accessibility labels are preserved. The selected design is custom and does not use an icon library.
